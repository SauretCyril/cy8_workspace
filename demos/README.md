# 🎮 Répertoire Demos

## 📋 Contenu

Ce répertoire contient les **fichiers de démonstration** et d'exemple pour le projet `cy8_prompts_manager`.

### 📁 Fichiers présents :

- **`demo_images.py`** : Démonstration du système de gestion d'images et galerie
- **`demo_rag_system.py`** : Démonstration du système RAG (Retrieval-Augmented Generation)

### 🎯 Objectif

Les scripts de démonstration permettent de :
- 🧪 **Tester les fonctionnalités** en mode standalone
- 📚 **Illustrer l'utilisation** des différents composants
- 🔍 **Valider le comportement** des systèmes complexes
- 📖 **Fournir des exemples** d'implémentation

### 🚀 Utilisation

```bash
# Activer l'environnement virtuel
.\venv\Scripts\Activate.ps1

# Lancer une démonstration
python demos/demo_rag_system.py
python demos/demo_images.py
```

### 📝 Note

Ces fichiers sont destinés à des fins de **démonstration et d'apprentissage**. Ils ne font pas partie du code de production principal mais servent à comprendre et tester les fonctionnalités.
